# TK Rules

Active for every TK agent, every mode, every time. Enforced silently.

- No placeholder code (TODO, FIXME, "implement later")
- No hardcoded secrets or API keys — secrets come from `.env` / env vars only
- No browser alert(), confirm(), prompt()
- All async operations must have error handling
- No emojis in code, comments, or output
- No em dashes in UI copy

## Gatus-specific

- Never edit `web/static/` by hand. It is generated by `make frontend-build`
  and embedded via `//go:embed`. Edit `web/app/src/` and rebuild.
- After adding or updating a Go dependency: `go mod tidy && go mod vendor`.
- Unprotected API routes register BEFORE `ApplySecurityMiddleware`; protected
  routes register AFTER. Order matters.
- In `config/config.go` `parseAndValidateConfigBytes`, `ValidateAlertingConfig`
  must run before `ValidateEndpointsConfig`.
- All Vue components need `dark:` prefixed Tailwind classes.
- Props-based data flow in Vue. Do not use provide/inject.
- Deploy rule: only edit LOCAL docker config. Never push or deploy to prod —
  the user does that with `./update.sh` on the box.
